
# CS 5800 - Quiz 2

## Overview
This project demonstrates Test-Driven Development (TDD) using Java, Maven, and JUnit 5.

## Components
- Calculator: Arithmetic operations and even-number checking.
- DateChecker: Checking whether a calendar month has 31 days.

## Development Process
The project follows the Red-Green-Refactor cycle:
1. Write a failing unit test (Red).
2. Implement the minimum code to pass the test (Green).
3. Refactor while keeping all tests passing.

## Technologies
- Java 26
- Maven
- JUnit 5

## Running Tests
Run the following command from the project directory:

mvn test
